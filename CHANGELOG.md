# Changelog

## [0.3.4] - 2026-11-10

### Added

- Daily quests that pick a random set of notes to revisit, with a goal you can adjust.
- Progress that counts each selected note once, plus current streak, best streak, and total completed quests.
- Previous and next note navigation, a ribbon shortcut, and commands to open the quest or the next find.
- A source folder and exclusions for files, folders, and tags.
- Optional in-app reminders with a configurable interval and a one-hour snooze.
- English and Russian interface text.
